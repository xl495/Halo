# Halo

悬浮倒计时。圆环、胶囊、卡片或只显示时间，多款主题，始终置顶。

用 **Tauri** 打包，安装包大约几兆到十几兆。

## 下载

在 [Releases](https://github.com/xl495/Halo/releases) 下载最新版：

| 系统 | 文件 |
| --- | --- |
| macOS（Apple Silicon） | `.dmg` |
| Windows | NSIS `.exe` |

**Mac 第一次打开：** 右键图标 → 打开（未做苹果公证）。  
**Windows：** 若 SmartScreen 提示，选「更多信息」→「仍要运行」。

## 用法

- 拖动圆环移动
- 悬停显示暂停 / 重置 / 设置
- 空格 暂停或继续 · R 重置 · S 设置
- 托盘图标可重新打开设置窗口
