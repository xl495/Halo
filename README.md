# Halo

悬浮倒计时。圆环、胶囊、卡片或只显示时间，多款主题，始终置顶。

## 下载

打包完成后在 [Releases](https://github.com/xl495/Halo/releases) 下载：

| 系统 | 文件 |
| --- | --- |
| macOS | `Halo-1.0.0-mac.zip` 或 `.dmg` |
| Windows | `Halo Setup 1.0.0.exe` |

**Mac 第一次打开：** 右键图标 → 打开（未做苹果公证）。  
**Windows：** 若 SmartScreen 提示，选「更多信息」→「仍要运行」。

## 用法

- 拖动圆环移动
- 悬停显示暂停 / 重置 / 设置
- 空格 暂停或继续 · R 重置 · S 设置
- 托盘图标可重新打开设置窗口
